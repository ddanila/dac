Match the board revision first.

The owner identified this monitor as K7222.25 from photographs and internal construction. Its external plate carries only the serial number. The installed board revisions have not been recorded. No complete schematic set verified against this particular monitor has been located; the related .11/.21 and .13/.23 drawings below must be checked against the actual boards.
