Paste through the keyboard

Wait for the program’s prompt. Text is typed at a controlled pace; newlines press Enter. Printable ASCII, up to 4096 characters. Reference S600 layout only when keyboard firmware is loaded.

Record and replay a session

Restart and record captures the current disks, ROMs and subsequent keyboard, disk changes, reset and power events. Export contains that media; keep its original credits. Replay checks the display, disks and printer in a separate machine. Maximum 100,000 events and eight disk changes.

Disk library

Named copies stay in this browser. Power off to insert or reset one. Duplicate makes an independent copy; reset restores that copy’s original contents.

Keep this session

Writable disk copies save automatically. Export a disk for a portable backup. Machine states resume the selected machine with the same media. Older exported states can use a preserved emulator version when available.

Printer output

Busy, offline and paper out all deassert the printer’s CTS ready signal. Software that ignores readiness can lose output; no printer-specific escape language is simulated.

Text preview interprets CR, LF, tab, backspace and page feed. Other control bytes appear as ⟦hex⟧; no particular printer’s escape language is assumed.
